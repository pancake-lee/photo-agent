## 1. 专题总览

### 1.1 问题一句话

主题发现（`suggest.py`）产出的选题建议中，每组照片都是时间接近、场景接近的高相似度组合，不符合「发现用户在图库中没轻易看到的角度」的功能初心。

### 1.2 核心矛盾

算法在找「共同点」，但选题发现的价值在「对比/连接」。

### 1.3 解决方案

三阶段编辑视角提案：随机采样 → LLM 主题直觉 → RAG + 多样性约束扩展选片 → LLM 沉淀完整选题提案。原有三维度保留为备选回退路径。

## 7. 设计决策记录

- **方案选择**：方案 B「新增跨上下文发现维度」为用户自创的三阶段方案提供了出发点，最终方案融合了方案 B 的结构化流程和方案 C 的「编辑视角」理念
- **与现有维度的关系**：原有三维度（高频未成组/时间线规律/稀缺优质）保留为回退路径，在主路径不可用时自动降级
- **随机采样的合理性**：不视为「放弃控制」，而是引入 LLM 不会主动探索的组合路径，打破共享属性优先的惯性
- **约束位置**：Stage 2 做了日期多样性（`_STAGE2_MAX_PER_DATE=2`），但 Stage 3 LLM 自由选择时可绕过——这是 B9 的根因
