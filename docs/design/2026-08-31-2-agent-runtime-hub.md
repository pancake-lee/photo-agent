# Agent Runtime — 专题中枢

> 本文档是「Agent Runtime V1」的唯一中枢，汇总 AR 系列的设计、实施、验收与评估产物。
> 后续围绕 Runtime 的规划、开发与评估均以本文档为入口。

## 1. 专题总览

- **目标**：让开放的“选片并创作”请求以状态化多步执行完成，不再为每个组合需求新增专用管线。
- **当前完成度**：AR、AR1–AR14、AR2-1–AR2-7 与 AR3-1–AR3-5 均已关单；AR3-6 至 AR3-8 为本轮复评新登记的待规划问题。
- **当前阶段**：V3 已完成离线交付复评（6.3/10），但跨期两期范围、主题发现入口和完整组合轨迹尚未闭合；真实数据/真实 LLM 回归仍需用户在单独轮次明确授权。
