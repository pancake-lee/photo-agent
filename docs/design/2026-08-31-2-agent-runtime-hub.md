# Agent Runtime — 专题中枢

> 本文档是「Agent Runtime V1」的唯一中枢，汇总 AR 系列的设计、实施、验收与评估产物。
> 后续围绕 Runtime 的规划、开发与评估均以本文档为入口。

## 1. 专题总览

- **目标**：让开放的“选片并创作”请求以状态化多步执行完成，不再为每个组合需求新增专用管线。
- **当前完成度**：AR1–AR8、AR10 全部 Done（AR8 实时过程反馈与 AR10 入选照片文件名均经用户 2026-09-01 验收确认）。AR9 已规划（方案细化完成），为当前唯一待实施项。原始山西请求可完成流程并实时展示过程，但其选图和文案不满足用户的硬条件，正确性待 AR9 修复后重新验收。
- **当前遗留**：SQL 空结果后全库 RAG 会丢弃已确认的旅行/日期/时段约束，完成检查未验证入选照片的范围归属（AR9 方案已定，待实施）。
