# Agent Runtime — 专题中枢

> 本文档是「Agent Runtime V1」的唯一中枢，汇总 AR 系列的设计、实施、验收与评估产物。
> 后续围绕 Runtime 的规划、开发与评估均以本文档为入口。

## 1. 专题总览

- **目标**：让开放的“选片并创作”请求以状态化多步执行完成，不再为每个组合需求新增专用管线。
- **当前完成度**：AR1–AR7 全部 Done。AR8 的真实验收发现页面未随 SSE 事件重绘，尚未关单；AR9 已登记为检索硬约束失守和错误交付阻断。原始山西请求可完成流程，但其选图和文案不满足用户的硬条件，不能作为正确性验收通过的证据。
- **当前遗留**：一是 Runtime 过程事件已产生却未被前端实时渲染；二是 SQL 空结果后全库 RAG 会丢弃已确认的旅行/日期/时段约束，完成检查未验证入选照片的范围归属。
