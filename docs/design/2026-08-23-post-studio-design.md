### 图文工坊 — 设计文档

衍生设计：[图文工坊提示词结构](2026-08-24-1-post-studio-prompt-design.md)（PS6）

### 1. 背景与动机

用户旅行归来后，有“按天或按景点把照片整理成分享帖子”的刚性需求。当前主题发现是 AI 主动推送选题（push），用户无法指定具体照片和场景。图文工坊补齐 pull 模式——用户带着明确的照片和意图进入，AI 辅助生成帖子文案。

**核心价值**：主题发现解决了“不知道发什么”，图文工坊解决“知道发什么但写不好”。

### 2. 功能关系定位

本项目围绕“生成帖子”这一核心目标，设计了四条协作路径：

| 功能               | 定位                                | 协作关系                             |
| ------------------ | ----------------------------------- | ------------------------------------ |
| **图片管理** | 数据基础层。上传/展示/VLM/Embedding | 手动选图 → 进入图文工坊             |
| **主题发现** | 核心亮点。AI主动策展，输出选题提案  | 采纳提案 → 进入图文工坊，内容预填   |
| **图文工坊** | 创作工作台。编辑帖子、生成文案      | 接收以上两路输入，保存草稿到草稿管理 |
| **草稿管理** | 统一管理所有草稿                    | 点击 → 继续进入图文工坊编辑         |

**两条创作路径并行**：

- **路径 A（AI策展）**：用户不知道发什么 → 主题发现生成选题提案 → 采纳 → 图文工坊预填内容 → 编辑 → 发布
- **路径 B（自选图片）**：用户知道要发什么 → 图片管理勾选照片 → 图文工坊 → 编辑 → 发布

两条路径独立平等，最终汇合到图文工坊完成编辑。主题发现因其“主动挖掘用户没想到的角度”的设计意图，保持独立入口和完整流程，不被图文工坊包含。

**页面跳转关系**：

```
图片管理 ──选择照片──→ 图文工坊
主题发现 ──采纳提案──→ 图文工坊
图文工坊 ──保存草稿──→ 草稿管理
草稿管理 ──继续编辑──→ 图文工坊
```

### 3. 菜单结构调整

为承载以上功能关系，左侧菜单栏调整为以下顺序：

```
📷 Photo Agent
│
├── 📸 图片管理          ← 数据基础，多选入口
├── ✨ 主题发现          ← AI策展入口（核心亮点）
├── ✏️ 图文工坊          ← 创作工作台核心
├── 📂 草稿管理            ← 草稿统一管理
├── 💬 新建对话          ← AI对话入口
├── 📋 对话列表          ← 历史对话管理
├── ⏱️ 时间线            ← 可选辅助功能
├── 🔧 黄金用例          ← 开发测试工具
└── ⚙️ 设置             ← 系统配置
```

### 4. 图文工坊（核心页面）

**页面布局**：单栏（照片区在上，文案区在下），内容区最大宽度 960px 居中。顶栏为「图文工坊」标题 +「保存草稿」按钮（编辑草稿时显示“编辑草稿”标记）。

**照片区**

- 已选照片的缩略图网格，支持拖拽调整顺序（vuedraggable）
- 每张照片可移除（右上角 × 按钮）
- 点击照片缩略图 → 打开照片详情大图（见下文「照片详情大图查看」）
- 点击“添加照片”打开图片选择器（关键词搜索 + 复选），补充照片
- 空状态提示“暂无照片，点击「添加照片」开始选择”

**文案区**

- **风格选择器**：下拉框提供文艺 / 纪实 / 轻松 / 攻略四种常用风格，同时支持直接输入自定义风格（filterable + tag）；默认「轻松」
- **模式切换**：提示词 / 草稿润色，二选一，与风格选择器同一行、居中
  - 提示词按钮为蓝色（primary），草稿润色按钮为黄色（warning），用颜色强化当前模式
  - 两种模式共用一个输入框，切换时各自内容保留、框高不变
- **输入框**：提示词 / 草稿内容共用；提示词模式自动预填默认提示词（描述要求与方向，非帖子内容本身）
- **生成按钮**：位于输入框下方
  - 提示词模式始终可点（照片为空时点击提示“请先添加照片”）
  - 草稿模式无输入时置灰禁用，placeholder 为“请输入文案”
- **标题输入框**：位于生成按钮下方（标题与正文一起由 AI 生成后填入）
- **正文编辑区**：AI 生成内容填入，用户可自由编辑

**两种生成模式**：

- **提示词模式**：输入要求 → 点击“生成文案”，AI 根据照片描述 + 风格 + 提示词生成标题和正文
- **草稿模式**：粘贴草稿文本 → 点击“润色文案”，AI 在保留原文结构基础上润色优化

**照片详情大图查看（图文工坊与图片管理共用）**：

- 点击照片打开全屏灯箱，不遮挡左侧菜单栏（只在右侧子页面内）
- 左侧半透明遮罩上叠加放大的原图（非缩略图），左右按钮切换上一张/下一张，底部显示 `i / N` 计数，顶部显示文件名
- 右侧详情面板（实色底，与图片管理原详情抽屉一致）：EXIF 参数、AI 描述、Embedding 向量
- 「退出」按钮、点击遮罩、Esc 关闭；←/→ 键盘切换上/下一张
- 图文工坊与图片管理的上/下一张 UI/UX 一致，但列表不同：图片管理为当前加载的照片窗口，图文工坊为已选帖子的照片列表
- 图文工坊内只展示信息，不显示 VLM/Embed 处理按钮

**两种生成模式的设计考量**：将“生成”和“润色”分为两种独立模式而非用同一按钮区分，让用户进入页面时清楚地知道当前处于哪种状态，避免混淆。

### 5. 草稿管理

**页面布局**：参考主题发现当前布局，但字段信息不用完全一致

**字段信息**：

- 标题（点击进入图文工坊继续编辑）
- 照片
- 文案
- 创建时间 / 最后修改时间
- 来源标记：主题发现 / 自选图片
- 状态：草稿 / 已发布

**操作**：

- 编辑 → 进入图文工坊继续编辑
- 删除 → 确认后移除
- 状态切换 → 草稿 ↔ 已发布

### 6. 入口：图片管理多选模式（现有图片管理页面的改造）

**触发方式**：图片管理顶栏增加“选择模式”切换按钮（与普通浏览模式互斥）。

**选择模式下的交互**：

- 每张照片显示复选框
- 顶栏显示已选数量 + “图文工坊”按钮
- 支持全选 / 取消全选
- 支持**区间选择**：选中2张照片后，顶栏出现“区间选择”按钮，点击后勾选这两张之间（按拍摄时间排序）的所有照片
- 连拍组展开后子图可单独选中

**进入图文工坊**：点击“图文工坊”按钮，携带已选照片跳转。

### 7. 入口：主题发现采纳提案（现有主题发现页面）

主题发现生成选题提案后，右上角增加「采纳此选题」按钮。

点击后跳转到图文工坊页面，内容预填：

- 照片序列 → 照片区
- 标题 → 标题输入框
- 叙事角度 → 正文编辑区（作为第一段或标题下方引言）

用户进入后可直接编辑、调整，确认后保存。

### 8. 草稿导出

在图文工坊中，完成编辑后可进行导出操作：

- **文本导出**：
  - 复制为 Markdown
  - 复制为纯文本
  - 下载为 .md 文件（包含标题和正文）
- **图片导出**：
  - 帖子关联的照片提供原图下载
  - 支持单张下载
- 支持一键打包为 ZIP 下载：原图和.md文件

导出的文本和图片可自由组合，用于发布到不同平台。

### 9. 关键决策记录

**决策：主题发现保持独立入口，不被图文工坊包含**

- 主题发现体现“系统主动挖掘用户没想到的角度”的设计意图，是项目的核心差异化能力
- 将其降级为子功能会降低可见性，导致用户错过最佳使用路径
- 图文工坊作为平行入口提供自选图片路径，两者平等并存

**决策：图文工坊作为创作工作台的中心页面**

- 无论用户从哪条路径进入，最终汇合到同一个编辑界面，降低学习成本
- 草稿管理作为统一持久化层，形成“多种入口 → 统一编辑 → 统一管理”的闭环

**决策：采用“提示词生成”和“草稿润色”双模式**

- “提示词生成”应对用户有想法但不会表达的场景
- “草稿润色”应对用户已有初稿但需要润色的场景
- 两种模式共用同一编辑区，无缝衔接
- 用二选一的按钮切换方式，让用户明确当前处于哪种生成/润色模式，避免混淆

**决策：图文工坊 UI 细化为单栏 + 风格下拉可自定义 + 模式按钮着色**

- 布局收敛为单栏（照片区在上、文案区在下），避免左右两栏在窄屏下的自适应复杂度
- 风格选择器用下拉框（filterable + tag）同时支持选择常用风格和直接输入自定义风格，兼顾快捷与灵活
- 标题移到生成按钮下方，与正文一起由 AI 生成，突出“生成”这一核心动作
- 提示词/草稿模式用按钮颜色（蓝/黄）区分，切换时各自内容保留

**决策：照片详情大图查看（灯箱）为图文工坊与图片管理共用**

- 复用图片管理的 PhotoDetail 组件，升级为“全屏灯箱 + 右侧详情面板”，支持上/下一张
- 图文工坊与图片管理共用同一组件，仅导航列表不同（工坊=已选照片，图片管理=当前照片窗口）
- 图文工坊内只读展示，不提供 VLM/Embed 处理入口
