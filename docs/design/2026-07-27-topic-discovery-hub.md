## 1. 专题总览

### 1.1 问题一句话

主题发现（`suggest.py`）产出的选题建议中，每组照片都是时间接近、场景接近的高相似度组合，不符合「发现用户在图库中没轻易看到的角度」的功能初心。

### 1.2 核心矛盾

算法在找「共同点」，但选题发现的价值在「对比/连接」。

### 1.3 解决方案

三阶段编辑视角提案：随机采样 → LLM 主题直觉 → RAG + 多样性约束扩展选片 → LLM 沉淀完整选题提案。原有三维度保留为备选回退路径。

## 5. 下一轮优化建议

### 5.1 最优先：B8 + B9（阻塞原始验收标准）

这两个问题直接关联原始方案的未完成验收项：

- **B8**：在 `_stage3_generate_proposals` 中，对 LLM 返回的每个 photo_id 做数据库存在性校验。无效 ID 从 expanded 候选列表中取未使用的真实 ID 替换（而非丢弃整条提案）
- **B9**：在 Stage 3 的 LLM prompt 中增加时间多样性要求，或在后处理阶段对最终 photo_sequence 做时间跨度硬校验。核心目标：每条选题的照片时间跨度 ≥ 7 天

### 5.2 其次：R6（随手 cleanup）

将 `import re` 从函数体内联提升到 `suggest.py` 模块顶部，删除两处内联 import。

### 5.3 验证方式

B8/B9 修复后，建议做一轮专题评估，重点检查：
- photo_id 全部有效（无截断/幻觉）
- 每条选题时间跨度 ≥ 7 天
- 叙事质量不退化（评分 ≥ 7.0）

## 7. 设计决策记录

- **方案选择**：方案 B「新增跨上下文发现维度」为用户自创的三阶段方案提供了出发点，最终方案融合了方案 B 的结构化流程和方案 C 的「编辑视角」理念
- **与现有维度的关系**：原有三维度（高频未成组/时间线规律/稀缺优质）保留为回退路径，在主路径不可用时自动降级
- **随机采样的合理性**：不视为「放弃控制」，而是引入 LLM 不会主动探索的组合路径，打破共享属性优先的惯性
- **约束位置**：Stage 2 做了日期多样性（`_STAGE2_MAX_PER_DATE=2`），但 Stage 3 LLM 自由选择时可绕过——这是 B9 的根因
