招聘岗位：AI研发工程师（1-2名）

  • 职级： 中级/高级工程师
  • 汇报对象： 技术经理 / AI产品经理
  • 核心使命： 与AI产品经理紧密协作，将业务场景转化为稳定、高效、可扩展的AI工程化解决方案，支撑公司“智能员工集群”的快速开发与迭代。

一、 岗位职责

1. AI Agent 与 RAG 系统开发

  • 负责企业级AI Agent（智能体）的后端开发与部署，基于LangChain、LangGraph、Dify等框架构建具备记忆、工具调用、多轮对话能力的智能应用。
  • 参与RAG知识检索系统的优化，实现文档解析、向量化存储、混合检索（Hybrid Search）、重排序（Rerank）等关键模块，持续提升检索准确率与响应速度。

2. 模型工程化与API服务

  • 负责大语言模型（包括开源模型如Qwen、Llama及闭源API如GPT、文心等）的接入、封装与性能调优，设计高可用、低延迟的推理服务。
  • 探索模型微调（LoRA、QLoRA）及Prompt Engineering（CoT、ToT），针对业务场景提升模型输出质量。

3. 数据处理与自动化管线开发

  • 配合数据治理规范，编写数据清洗、特征提取、格式转换等ETL任务，为AI应用提供高质量的数据输入。
  • 开发Text-to-SQL、对话式BI等后端逻辑，打通业务数据库与自然语言交互之间的技术链路。

4. 系统集成与工程化落地

  • 将AI能力封装为标准API或可嵌入业务的SDK，与公司现有OA、IM、BI等系统进行集成。
  • 参与AI应用的全链路监控与日志分析，建立错误重试、降级兜底、成本追踪等工程保障机制。

5. 技术文档与协作

  • 编写技术设计文档、接口文档及部署运维手册，确保AI模块的可维护性与可扩展性。
  • 与AI产品经理、前端/后端工程师、测试人员高效协作，参与需求评审、技术方案评审及迭代发布。

二、 任职要求

1. 基础能力

  • 计算机、软件工程、数学或相关专业本科及以上学历，3年以上后端开发经验，其中至少1年以上AI应用开发经验。
  • 熟练掌握 Python，具备良好的编码规范与工程组织能力，熟悉FastAPI、Flask等Web框架。

2. AI工程能力

  • 熟悉 LangChain 或 LangGraph 框架，有基于该框架开发Agent或链式调用（Chain）的实际项目经验。
  • 熟悉 RAG 技术栈：掌握向量数据库（如Milvus、Chroma、Pinecone、FAISS之一）的使用与优化；了解文档分块、Embedding模型选择、检索召回策略。
  • 了解大模型API调用（OpenAI、Anthropic、国内主流模型），了解常见提示词工程技巧。

3. 数据处理与数据库

  • 熟练使用 SQL，熟悉至少一种关系型数据库（PostgreSQL、MySQL）。
  • 具备基本的数据处理能力（Pandas、正则表达式、JSON解析等）。

4. 工程素养

  • 熟悉Git协作流程，了解Docker容器化部署，具备基本的Linux运维能力。
  • 具备问题排查能力，能够对AI应用中的常见异常（超时、格式错误、检索无结果）进行快速定位与修复。

5. 软实力

  • 逻辑清晰，能够理解产品经理提出的业务需求，并将其拆解为可落地的技术方案。
  • 具备良好的沟通能力，乐于主动反馈进度与风险，适应敏捷开发节奏。

三、 加分项

  • 有 LangGraph 或 AutoGen 多智能体协同开发经验。
  • 有模型微调（LoRA、Full Fine-tuning）实战经验，或在公开榜单/比赛中获得过名次。
  • 熟悉 Dify、FastGPT 等低代码AI应用平台，并能进行二次开发。
  • 有 Text-to-SQL 或 NL2SQL 相关项目经验。
  • 对LLM工程（如vLLM、TGI推理加速、流式输出、函数调用）有深入实践。
  • 在GitHub上有开源AI项目或贡献过相关代码。
