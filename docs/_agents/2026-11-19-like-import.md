## 核验依据

- 匹配使用 JPG 的 SHA256，并核对 NEF/JPG 的拍摄时刻、相机型号、机身编号和快门计数；不按同名强配。
- 通过现有归档 API 完成预览、上传及入库；NEF 在数据库关联、目标摘要和源文件不变核对通过后才删除 like 中的副本。
- 883 个文件通过 SHA256 核对，包含目标文件、保留的 JPG/HEIC、未匹配 NEF 及已有 HEIC 原件。
- 原有 1,794 条照片完整字段摘要不变；3,588 个已有 JPG/预览的设备号、inode、大小和修改时间不变。
- 既有归档记录的收藏和 JPG 摘要保持不变，匹配的 163 条仅更新 NEF 摘要和归档键；SQLite integrity_check 为 ok。
- 通过公开图片列表接口读取 18 页，163 张目标照片全部返回 hasNef=true。
- 本地过程材料在 `.local/like-import-2026-11-19/`，仅存清单、状态摘要和脚本，没有重新创建 exports/backups 或复制整套照片备份。
