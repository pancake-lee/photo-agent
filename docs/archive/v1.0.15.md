# v1.0.15 版本归档

> 归档日期：2026-08-30  
> 涵盖范围：v1.0.14（2026-08-28）之后完成的任务  
> 版本主题：**工程质量基线、配置收敛与运行数据治理**

## 版本概述

本版本完成图文工坊草稿编辑输入恢复，并以一次后端质量评估为起点，收口数据安全、外部调用边界、关键用户路径自动化和 Service 数据访问职责；同时完成公共文档、开发工具、运行数据与配置契约的系统整理。

**关键结果**：

- 完成 PS10、BQ1–BQ2、BQ4–BQ6、BQ8–BQ11、DOC2、TIDY1–TIDY4、CFG1–CFG7，共 22 项任务
- 草稿可恢复创作模式及对应编辑输入；相关自动验证已完成
- 移除旧列删除与完整配置日志，Embedding 调用具备显式时限与取消传播
- 关键测试从生产迁移产出的 SQLite schema 基线运行，VLM 队列经公开入口覆盖成功、失败、停止闭环
- 配置模板收敛为共享功能段与服务专属地址，配置、评估规则和价格表均在加载边界校验
- 活跃运行数据、开发工具及公共文档的目录和契约与当前实现一致

## 主要变更

### 后端质量与可证明性

- 建立后端代码质量评分标准、基线报告、复评报告和专题中枢；评估范围由 `tools/go/main.go --self-check` 固化。
- 删除一次性的旧 AI/VLM 状态列删除迁移，移除完整配置日志，避免数据不可逆风险和凭据泄露。
- Embedding 外部调用使用受限上下文与显式 HTTP 时限；成功、超时、取消及失败均有本地 HTTP 测试。
- 数据访问职责收敛至 `data` 层；测试复制由生产迁移生成的无业务数据 SQLite schema 基线，不再以手写 DDL 建表。
- VLM 队列通过公开启动/停止入口和本地 HTTP 替身验证成功、失败与停止后的最终持久化状态。

### 配置、工具与运行数据治理

- 统一共享的 Storage、LLM、VLM、Embedding、RAG 等功能配置，服务监听与代理地址从专属配置段派生。
- 删除 Dify、废弃 `descriptions.json` 入库脚本及无消费者配置；配置、评估规则、价格表均在加载边界执行明确校验。
- 价格表统一为人民币、元/百万 Token；当前实际价格仍只由用户维护在 `.local/prices.yaml`。
- 工具目录按 Go/Node 分层；运行数据重排为后端、Agent、主题发现和执行 Trace 的明确归属，淘汰文件移入 `data/bak/2026-08-30-data-audit/`，未删除材料。

### 产品与文档体验

- 图文工坊草稿完整保存提示词模式/润色模式及其对应输入，并在重新编辑时回填。
- README、PRD、技术、部署与审阅规范同步当前 API、数据模型、分块策略、目录与配置事实。

## 验证结果

- `GOTOOLCHAIN=local go test ./...`、`go vet ./...`、受影响包 race 检查均通过。
- Agent 100 项单元测试、配置加载与评估规则加载、黄金用例解析均通过；Web 生产构建与 Node 工具语法检查通过。
- SQLite/Chroma 元数据完整性、选题历史 Trace 回放、活动路径扫描、`git diff --check` 均通过。
- PS10 的两种草稿模式恢复由用户于 2026-08-30 确认通过。

## 已知边界与后续入口

- BQ3 仍暂缓：当前仅可在受信任的本地开发环境使用自由只读 SQL；进入共享、多人或生产环境前必须按 [FR-11](../design/2099-01-01-future-requirements.md#fr-11-开发阶段的鉴权与自由-sql-查询收敛) 恢复鉴权并收紧查询能力。
- CQ4 已完成自动实现与单元测试，仍待真实 Agent 环境中重发山西请求后验收；详见 [backlog CQ4](../backlog.md#cq4-创作型查询compose专用管线)。
