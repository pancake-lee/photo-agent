# v1.0.11 版本归档

> 归档日期：2026-08-25  
> 涵盖范围：v1.0.10（2026-08-22）之后完成的任务  
> 版本主题：**图片 AI 闭环与图文工坊**

## 版本概述

本版本完成图片管理的 VLM 实时生成、Embedding 入库闭环，并清理旧的
`descriptions.json`/AutoSync/batch_vlm 机制；同时交付图文工坊从选图、主题采纳、
AI 文案生成与润色到草稿管理、照片详情和导出的完整工作流。

**关键结果**：

- 完成 CL1、CL2 与 PS1–PS6，共 8 项任务
- 图片管理闭环评估 8.4；图文工坊系列评估 7.8–8.5
- VLM 描述与生成时间迁入数据库，Embedding 直接写入 Chroma
- 图文工坊支持自选照片与主题发现两条入口、草稿持久化、照片大图查看及 ZIP 导出
- 提示词重构修复照片描述未传入 LLM 的根因，并加入结构化输出与缺描述提示

## 主要变更

### 图片 AI 闭环（CL1-CL2）

- 上传照片后可实时调用 VLM 生成结构化描述并写入数据库，批量 VLM 与 Embed 按缺失数据处理。
- `description_model`/`description_time` 迁入 `photos` 表；详情页直接读取数据库。
- 删除 descriptions.json、AutoSync 目录扫描导入及 batch_vlm 遗留机制，上传成为唯一导入路径。
- VLM HTTP 客户端增加 60 秒超时，单张超时不会阻塞后续队列任务。

### 图文工坊（PS1-PS6）

- Go 侧提供草稿 CRUD 与 ZIP 导出；Python 侧提供文案生成和润色接口；Vue 侧提供工坊、草稿管理及菜单入口。
- 图片管理支持多选、区间选择和连拍组精选，可携带照片进入工坊；主题发现可直接采纳提案并预填内容。
- 照片详情升级为避开左侧菜单的全屏灯箱，支持按钮和键盘切换；工坊与图片管理共用组件。
- 文案上下文改为结构化照片摘要，支持风格、照片顺序、攻略 EXIF 与用户要求分层，输出采用 JSON 契约。

## 验证与遗留验证

- 已完成相关 Go 单测、Python 测试与前端构建自检。
- （用户）部署后验证 PS6 生成文案能准确引用照片主体和场景，并检查四种风格差异。
- （用户）部署后验证照片拖拽顺序影响叙事顺序，润色不引入照片外事实。
