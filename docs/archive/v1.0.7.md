**关键数字**：

- 三阶段主路径经历 **6 轮评估**，评分从 4.2/10 提升至 8.0/10
- 修复 **11 个缺陷**（B1/B3/B4/B5/B6/B7/B8/B9/B10/B11 + 旧数据兼容）
- 完成 **4 项工程改进**（R4/R5/R6/E5）+ 1 个装饰项（E4）
- 完成 **5 个 Phase 需求**（1.3/2.2/2.3/3.4/3.5）+ 2 个衍生交互优化（3.6/3.7）

## 一、主题发现：三阶段编辑视角提案

> 📋 中枢文档：[2026-07-27-topic-discovery-hub.md](../design/2026-07-27-5-topic-discovery-hub.md)
> 设计文档：[2026-07-27-2-suggest.md](../design/2026-07-27-2-suggest.md)

### 问题与方案

**3.4 主题发现选题相似度过高** — 原始 `suggest.py` 产出的选题建议中，每组照片时间接近、场景接近、风格接近，算法在找「共同点」，但选题发现的价值在「对比/连接」。

**方案**：重构为三阶段编辑视角提案管道：
1. **Stage 1**：随机采样 → LLM 生成 3 个主题直觉
2. **Stage 2**：RAG 检索 + 日期多样性约束（`_STAGE2_MAX_PER_DATE=2`）扩展选片
3. **Stage 3**：LLM 基于候选照片池沉淀完整选题提案（叙事角度 + 照片序列）

原有三维度（高频未成组/时间线规律/稀缺优质）保留为回退路径。

### 评估闭环（6 轮）

| 轮次 | 日期 | 评分 | 通过 | 关键发现 |
|------|------|------|------|----------|
| #1 | 07-27 | 4.2/10 | ❌ | 主路径 100% 回退（embedding 代理 500），选题与改进前一致 |
| #2 | 07-27 | 8.3/10 | ✅ | B4/B5/B6/R5 修复验证 |
| #3 | 07-27 | 5.8/10 | ❌ | 主路径仍因配置缺失未激活，发现 B7 |
| #4 | 07-27 | 7.0/10 | ✅ | 主路径首次端到端跑通，选题质量明显提升 |
| #5 | 07-27 | 6.5/10 | ✅ | B8/B9/R6 验证，发现 B10（shot_at 时间戳） |
| #6 | 07-28 | 8.0/10 | ✅ | B10 修复后全面评估，9/9 提案均满足验收标准 |

### 衍生缺陷修复链

**B1 主题发现返回空结果**：SQLite 中 1177 张照片的结构化属性全为空。根因是 AutoSync 首次运行时 parseVlmAttrs 尚未实现，后续仅在 description 变化时触发更新。修复：syncImportPhoto 和 syncUpdatePhoto 均调用 parseVlmAttrs。

**B4 Stage 2 RAG 检索失败**：Go 后端 `/v1/embeddings` 代理因配置段缺失恒定返回 500。修复：Go 配置模板补充 Embedding 段，错误日志增强。

**B5 前置检查缺失**：embedding 不可用时仍消耗 Stage 1 LLM token。修复：Go 侧新增 `/v1/embeddings/health`，Python 侧 Stage 1 前检查。

**B6 _fetch_all_photos 仅 300 张**：Go handler `page_size=500` 与 DAO 层截断到 100 不一致，导致分页计算错误。修复：handler 中前置 page_size 截断。

**B7 Embedding 配置部署缺失**：`.local/pancake.yaml` Go 段缺 `Embedding.APIKey`。修复：用户手动补配。

**B8 Stage 3 photo_id 无校验**：LLM 可能输出无效 UUID（截断、数字索引等）。修复：构建全库 valid_ids 集合，无效 ID 从扩展候选替换。在 3 轮 9 提案中正确捕获 12 次幻觉。

**B9 时间跨度约束未强制**：Stage 3 LLM 自由选择时可绕过日期多样性。修复：三层机制（prompt 硬性要求 + 候选日期展示 + 后处理替换）。

**B10 shot_at Unix 时间戳**：Go API 返回 Unix 时间戳，但 Python 全部按 ISO 日期处理，导致日期分组/跨度计算/B9 后处理全部失效。修复：新增 `_parse_shot_date` 统一处理两种格式，全链路 8 处调用点修复。

### 工程改进

**R5 JSON 解析逻辑重复**：提取 `_parse_llm_json_response` 公共函数，两个解析函数改为一行调用。

**R6 import re 提升**：将 `import re` 从函数体内联移到模块顶部。

## 二、主题发现：持久化与交互

> 设计文档：[2026-07-28-1-suggest-persistence.md](../design/2026-07-28-1-suggest-persistence.md)

### 3.5 持久化存储 + 打分

选题生成结果原仅在前端 Vue ref 中临时持有，刷新后消失。新增：

- **Agent 层**：JSON 文件存储（`agent/data/suggest_history.json`），含文件锁并发控制
- **API**：5 个端点（history 列表/详情/删除 + rating 更新 + run 自动保存）
- **前端**：历史列表（时间倒序）+ 展开/收起 + 五星打分 + 删除
- **评估**：两轮均通过（7.9/10 + 7.5/10）

### 3.6 星级评分 hover 预览

3.5 评估中发现的交互优化：hover 星 N 时第 1-N 颗星临时变亮（`hoveredStar` 响应式状态 + mouseenter/mouseleave），hover 到当前评分时显示"取消评分"tooltip。

### 3.7 loadHistory 错误提示

3.5 第二轮评估发现：`loadHistory` 在 `!resp.ok` 和网络异常时均静默失败，用户无法区分空状态与错误。修复：catch 块和 HTTP 错误均用 `message.error` 提示。

### B11 星级评分无法取消

用户给主题打 3 星后无法取消到 0 星，因 hover 状态遮盖了评分变更的视觉反馈。修复：星星改为三态（空心灰/实心橙/发光橙 + scale(1.3) + text-shadow 光晕），hover 到当前评分时全部灭掉 + tooltip "取消"，点击时清除 hover 避免视觉遮盖。评估 8.4/10。

## 三、主图发现：聚类优化

### 2.2 聚类标题生成效果差

聚类标题输出"内容未识别"类无意义结果。根因两个：① SQLite 中 objects/colors/scene/lighting/mood 字段全为空（Go 后端只存了 description 文本）；② cluster.py 模板未使用 description。修复：Go 后端新增 `parseVlmAttrs()` 从 VLM JSON 中提取结构化字段，cluster.py 模板同时纳入属性 + 截断描述文本。

### 2.3 聚类详情页 UI 优化

评估结果从弹窗底部独立区域改为内嵌到每个簇卡片内部（按 cluster_id 分组），顶部新增「全部生成」「全部评估」按钮（含二次确认弹窗），汇总区展示通过率概览，每个簇可独立重新评估。

### B3 parseVlmAttrs 解析失败静默

parseVlmAttrs 在正则/JON 解析失败时静默返回空字符串，异常照片每次 AutoSync 都重试。修复：新增 `photoIdentifier` 参数输出 Warning 日志，全空且为 backfill 触发时跳过 DB 写入。
