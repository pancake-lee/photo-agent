1：基于pgo的go后端，可以直接迁移一份现成的监控配置，加入现有的prometheus/grafana/pyroscope中。
    configs/config.yaml 暴露端口10007

2：（计划）Agent/Web层的基本监控，先计划上，不执行，遇到问题需要指标需要日志时，我们在来插入任务
    - Agent
        - 可用性：Prometheus 是否能抓取指标。
        - 请求量：每秒请求数。
        - 错误率：HTTP 5xx 比例。
        - 耗时：请求 P95；聊天流式请求单独统计，避免与普通接口混在一起。
        - 资源：进程 CPU、内存。
    - Web
        - 首页是否可访问。
        - 首页响应耗时。
        - 暂不采集浏览器性能、前端异常和用户行为。
