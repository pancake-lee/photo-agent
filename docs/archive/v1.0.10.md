# v1.0.10 版本归档

> 归档日期：2026-08-22
> 涵盖范围：v1.0.9（2026-08-18）之后完成的任务

> 专题中枢：[2026-08-20-1-photo-list-hub.md](../design/2026-08-20-1-photo-list-hub.md)

## 版本概述

本版本完成 BG1 连拍分组：时间窗 + dHash + SSIM 灰区的传统算法识别，精细/模糊双档位分组，图片管理页三级展示切换与弹窗展开。

完成 LB1-LB8：照片列表从分页平铺升级为分段、可导航、双向滑动窗口浏览；修复高度链和导航锚点；补齐散片时间线与独立管理页；收敛图片管理顶栏，并完成页面组件拆分与遗留修复。

同时完成 D1-D2：Windows 客户端单实例启动，以及对话侧栏多选批量删除。

**关键结果**：

- 完成 BG1、LB1-LB8 与 D1-D2，共 11 项任务
- 列表浏览整体评估 8.1 / 10，子项评估范围 7.7–8.5
- `PhotoManagement.vue` 从约 1030 行拆为页面编排、顶栏、列表浏览三层职责
- 时间线事件由 JSON 迁入 `timeline_events`，支持散片自动分组和人工值保留
- 连拍分组全程传统算法零 token，识别结果落 `photo_groups` 表

## 主要变更

### 连拍分组（BG1）

- 识别链路：按 `shot_at` 时间窗划分候选组，dHash 汉明距离验证，灰区用 ImageMagick SSIM 二次确认，无 LLM 调用；结果落 `photo_groups` 表 + `photos.burst_group_id` 逻辑关联列。
- 重算为异步 goroutine + 进度轮询，与 VLM / Embedding 队列同模式，重复触发返回 already_running。
- 双档位：一次 rebuild 同时产出精细与模糊两档分组，阈值存 `app_settings` 表，设置页可编辑并附参数说明。
- 前端：图片管理支持全部展开 / 精细折叠 / 模糊折叠三级切换并持久化；封面角标 ×N，`BurstGroupModal` 弹窗内切换成员、设为封面、点主图进详情抽屉。
- 纯函数（时间窗分割、哈希切分、灰区 SSIM 判定）有单测覆盖。

### 列表浏览与导航（LB1-LB4）

- 按天、月或活动插入分割线，右侧导航可定位分段；排序收敛为拍摄时间升/降序。
- 改为连续滑动窗口：双向加载、相邻页预加载、窗口上限淘汰；`ListPhotoSegments` 返回与查询一致的 `offset` 和 `count`。
- 修复 naive-ui Layout 内层高度塌陷，确保只有照片列表滚动、滚动到边缘可持续加载。
- 导航高亮改按滚动容器相对坐标计算，跳转以分段首张照片卡为锚点。

### 时间线、顶栏与可维护性（LB5-LB8）

- 时间线事件迁入 `timeline_events`，首次加载导入旧 JSON；人工编辑以 `timeline_manual` 保留；散片按月生成 `YYYY-MM-散片N`。
- 新增时间线管理页和异步重算进度；图片管理顶栏收敛为单行 + 就地弹出面板。
- 拆分页面、顶栏、列表浏览组件；合并重复分页请求；辅助数据失败可见；分段键使用本地日期并补齐跨年边界测试。

### 日常小需求（D1-D2）

- D1：新 Windows 客户端以命名互斥体识别旧实例，通过 PID 替换旧实例，避免窗口双开和日志交错。
- D2：对话侧栏支持多选模式、删除确认、批量删除、当前会话重定向和空列表状态。

## 验证与遗留验证

- 已完成：相关前后端单测、`go test` 与 `pnpm build`（按各任务记录执行）。
- （用户）对真实照片库执行一次全量连拍 rebuild，人工抽检 50~100 组评估识别准确率与误归/漏归率，据此调阈值（BG1 P5）。
- （用户）在 `/timelines` 执行一次「重算时间线」，验证散片生成、人工值保留和活动导航锚点。
- （用户）在常用时区与东八区浏览一次跨日照片，确认本地日期分割线。
- （用户）在 Windows 实机验证 D1 双开及重编译后启动新 exe 的替换行为。

## 设计决策记录

- 连拍识别取「时间窗 + 内容相似度」传统算法，哈希复用 ImageMagick，组存独立表 + 逻辑关联列，rebuild 异步化。
- 连拍阈值拆精细/模糊两档，一次 rebuild 算两档；组展开由行内展开改为弹窗。
- 跳转策略从「筛选重置式」改为「窗口重定位」，优先保持浏览流连续。
- 散片在相邻活动区间内按月切分；重算保留人工值；时间线事件迁数据库表。
- 顶栏由三行收敛为单行 + NPopover 收纳。
