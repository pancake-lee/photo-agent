## 一、主题发现：交互式管线（3.8）

> 设计文档：[2026-08-01-topic-discovery-design.md](../design/2026-08-01-topic-discovery-design.md)

### 问题

主题发现是"黑盒"自动流程：用户点击按钮 → 等待 → 得到结果。两个体验缺口：

1. **不可见**：看不到 AI 内部处理步骤（采样了哪些照片、RAG 检索了什么、LLM 输出了什么）
2. **不可控**：无法微调中间结果，只能整体重跑

### 实现

**后端**（6 个端点）：
- `GET /api/suggest/history/{id}/detail` — 完整详情（含 versions + 管线步骤）
- `POST /api/suggest/history/{id}/rerun` — 从指定步骤重跑下游
- `POST /api/suggest/history/{id}/rerun-stream` — SSE 进度推送版重跑
- `PATCH /api/suggest/history/{id}/version/{vid}/switch` — 切换活跃版本
- `POST /api/suggest/manual-run` — 手动选题（自选照片 + 可选直觉）
- `POST /api/suggest/random-sample` — 独立暴露随机采样逻辑

**前端**（6 个新组件 + 1 个改造）：
- `SuggestDetailModal.vue` — 全屏详情 Modal
- `SuggestStepCard.vue` — 可折叠步骤卡片（折叠/展开/编辑三态）
- `SuggestStepEditor.vue` — 按步骤类型渲染编辑器
- `SuggestManualModal.vue` — 手动选题两步向导
- `SuggestPhotoSelector.vue` — 照片选择器（搜索 + 多选 + 分页 + 随机选取）
- `SuggestVersionTimeline.vue` — 版本时间线（已从详情弹窗中移除，后续可能恢复）
- `SuggestView.vue` — 按钮改为下拉菜单（自动/手动）

**可重入管线**：`_stage1_generate_intuitions` 和 `_stage3_generate_proposals` 增加 override 参数（`photo_ids_override` / `intuitions_override` / `prompt_override` / `expanded_photos_override`）。

**评估**：7.3/10（正确性 8 / 健壮性 8 / 可维护性 8 / 简洁性 7 / 完整性 7 / 一致性 9 / 惊喜度 6 / 可用性 7 / 交互体验 7）。

## 二、管线产出简化（3.11）

> 设计文档：[2026-08-01-topic-discovery-design.md](../design/2026-08-01-topic-discovery-design.md) §9.2

### 问题

一次 `POST /api/suggest/run` 产生：采样 6-9 张 → 2-4 个直觉 → 2-4 个提案 → 2-4 条历史记录（共享同一个 trace_id）。数据维度和展示维度不统一。

### 方案

采样参数收窄为 `_STAGE1_SAMPLE_MIN = _STAGE1_SAMPLE_MAX = 3`，prompt 改为输出 1 个直觉。最终 1 次运行 = 3 张采样 → 1 个直觉 → 1 个提案 → 1 条记录 → 1 个 trace_id → 1 个版本链。手动选题保持灵活性。

## 三、技术消债

### B13 双存储写入冗余

翻转依赖方向：v2 成为唯一数据源，v1 从独立存储变为 v2 的只读视图。存储函数统一（去 v2 后缀），锁统一。12 处写入点缩减为 5 处。

### 回退路径清理

删除 `suggest.py` 中三维度属性分析全部相关代码（`CandidateGroup`、`_check_embedding_health`、6 个分析函数、`_LEGACY_SUGGEST_SYSTEM_PROMPT`、`_build_legacy_prompt`、`_parse_legacy_response` 等），净删约 580 行。同步清理 `trace_replay.py`、`server.py` 和前端中的回退路径引用。

回退路径自 v1.0.7 以来从未被触发，保留它维护两套 prompt 和解析逻辑增加了不必要的复杂度。

## 四、功能增强

### 3.9 管线步骤可视化增强

- **照片缩略图网格**：采样/RAG/校验步骤展开时通过 Go API 批量加载照片缩略图，RAG 结果展示 distances 和 ratio_gaps，多样性过滤按日期分组展示因果关系
- **结构化编辑器**：直觉/提案步骤编辑器从 JSON 文本框改为表单
- **SSE 进度推送**：rerun-stream 端点推送阶段进度，前端展示进度条

### 3.10 选题版本对比功能

版本时间线增加对比模式，勾选两个版本展示差异：文本 diff（标题/角度/理由）、照片网格 diff（新增/移除/叙事角色变化）。纯前端实现。

### 步骤卡片照片展示增强（2026-08-01）

步骤卡片重写：RAG 匹配结果全量缩略图 + distances + ratio_gaps，多样性过滤按日期分组展示因果（保留/移除），提案解析展示缩略图 + role_in_narrative，有照片/payload 的步骤默认折叠数据区。

## 五、交互修复

### B12 手动选题直觉模式下照片被忽略

用户同时选照片 + 填直觉时，照片传入 `expanded_photos_override` 跳过 RAG，直觉跳过 Stage 1 LLM，两者同时生效。

### B16 卡片「详情」按钮替代整卡点击

移除整卡 `@click`，在卡片头部右侧新增独立「详情」按钮。解决文本选中/复制被整卡点击干扰的问题。

### B17 自动选题步骤数据为空

两处修复：(A) `POST /api/suggest/run` 创建条目时回放 trace 填充步骤；(B) `GET /api/suggest/history/{id}/detail` 检查空步骤并重新回放。

### B18 详情弹窗推荐照片展示缩略图

详情弹窗「最终结果」区 UUID 文本改为缩略图网格。
