# v1.0.16 版本归档

> 归档日期：2026-09-02  
> 涵盖范围：v1.0.15（2026-08-30）之后完成的任务  
> 版本主题：**Agent Runtime 落地与 Agent 工程治理**

## 版本概述

本版本将 Agent 从单发路由形态升级为状态化多步执行的 Agent Runtime V1，并以两次评估报告为起点，补齐真实闭环、过程反馈、检索约束保护与失败终态；同期完成 agent 目录三层重组、统一服务日志与 Trace 关联、价格配置故障隔离和黄金用例语义收紧。

**关键结果**：

- 完成 AR、AR1–AR10、TIDY5–TIDY7、CFG8、NAV1、OBS1、GQ1、EVAL1，共 20 项任务
- 开放目标请求（如山西发帖）经 decide/execute/reduce/check 循环完成，不再为组合需求新增专用管线
- 检索硬约束由权威范围物化保护，软提示永不清空候选，范围外入选在交付前被阻断
- 多步执行等待期间按真实 Runtime 事件实时显示用户可理解的过程，刷新后仍可回看
- agent 目录形成 `cli → internal → infra` 三层金字塔，依赖方向单向，import 风格统一限定调用
- 服务日志、Uvicorn 记录、会话消息与页面元信息可按同一 `trace_id` 关联
- Agent 单测从 100 项增长到 219 项全绿，前端测试与生产构建通过

## 主要变更

### Agent Runtime 多步执行

- 新增框架无关的 `agent/runtime/` 模块：TaskState、显式状态归约、确定性完成检查、预算（步数/时长/成本）和能力注册表；LangGraph 仅作编排外壳，组装 decide → execute → reduce → check 循环图。
- 入口路由新增 runtime 类别承接开放目标，CQ4 compose 专用管线删除，其折叠、收缩、深链逻辑迁入照片挑选能力；预算键落在 Agent 配置段。
- 能力异常、无效决策、旅行未匹配统一归约为确定性终态并给出可定位原因，不再反复消耗预算直至超限。

### 检索约束保护

- resolve_trip 扩展为约束解析能力：一次 LLM 调用抽取时间线、天序、时段与软提示，程序校验后只按硬约束拼装范围 SQL 并物化为权威候选范围；真实库 shot_at 混合时区经 `localtime` 统一换算。
- 归约层将候选类观察与权威范围求交集，软提示零命中时候选回落整个范围；hybrid_search 删除空结果回退全库 RAG 的替代语义。
- 范围为空时确定性终止并向用户说明条件与放宽建议；选片与完成检查双层校验范围归属，范围外入选在交付前被阻断。

### 过程反馈与可观测性

- 聊天接口改为单请求 SSE：真实 Runtime 事件归约为用户步骤快照持续推送，最终结果原子落为既有答案与照片；非 Runtime 查询不产生过程面板。
- 前端"执行过程"面板随 SSE 逐帧重绘（响应式代理更新 + happy-dom 逐帧测试锁定），执行期自动展开，终态恢复收起；快照随消息持久化，刷新会话仍可回看。
- 服务日志收敛为统一字段的 `logs/agent.jsonl`（应用与 Uvicorn 启动/access），`trace_id` 贯穿应用日志、Trace JSONL、即时响应、持久化回复与页面元信息。

### 工程与治理

- agent 目录重组为 `cli → internal → infra` 三层金字塔：入口集中 `cli/`，五个功能包（chat/topics/posts/runtime/evals）套入 `internal/`，基础设施下沉 `infra/`；功能包之间禁止互相 import，项目内模块统一 Go 式限定调用。
- 价格配置故障隔离：校验失败不再阻断服务启动，Token 用量保留但标识成本未追踪，Runtime 按价格可用性决定成本预算启停，健康检查暴露降级原因。
- 组图发现入口恢复至侧栏底部固定区；黄金用例保存资格收紧为仅纯 RAG 带照片回复；归档前阶段合理性专项检查规则落入评估指南与工作模式手册。

## 验证结果

- Agent 全量单测 219/219 通过（v1.0.15 时为 100 项），新增覆盖范围 SQL 拼装与时区换算、约束校验边界、软提示零命中兜底、范围外入选阻断、空范围终态、SSE 事件顺序与异常终态、SQLite 迁移、逐帧过程反馈。
- 前端 Vitest 13/13 通过（含 happy-dom 逐帧 SSE DOM 增量测试）；`pnpm build`（vue-tsc 类型检查 + Vite 生产构建）通过。
- 真实山西请求双路径经用户验收：第一天傍晚正常交付（44 张全部在权威范围内），最后一天傍晚（0 张）确定性终止并给出放宽建议。
- AR6、AR8、AR9、CFG8、NAV1、OBS1、TIDY6 由用户于 2026-08-31 至 2026-09-01 验收确认；其余任务以自动验证关单。

## 已知边界与后续入口

- BQ3 仍暂缓：当前仅可在受信任的本地开发环境使用自由只读 SQL，进入共享、多人或生产环境前须按 [FR-11](../design/2099-01-01-future-requirements.md#fr-11-开发阶段的鉴权与自由-sql-查询收敛) 恢复鉴权。
- 聊天 SQL 管线 few-shot 仍用裸 `DATE(shot_at)`，与库内混合时区不一致，跨午夜日期存在最多 8 小时语义漂移；AR9 已在 Runtime 范围 SQL 修正，聊天独立管线待同步，已登记为 backlog CQ7。
- CQ4 已取代关闭：专用管线由 Runtime 挑选能力承接，Compose 两个阈值配置继续复用。
