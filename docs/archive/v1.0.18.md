# v1.0.18 版本归档

> 归档日期：2026-09-07  
> 涵盖范围：v1.0.17（2026-09-07）之后完成或取代关闭的任务  
> 版本主题：**Agent Runtime V3 能力系统（Capability-Oriented Agent）**

## 版本概述

本版本将 Runtime 从"单一发帖目标的可靠循环"升级为"目标契约 + 能力库"架构：任务契约由目标拥有，能力按 Tool / Skill / Workflow 分层并具备机器可读契约；以只读的照片跨期对比作为第二开放目标验证复用主张，将既有主题发现管线封装为可调用的范围化 Workflow，并以完整图级轨迹与授权真实回归证明没有以新增端到端 Pipeline 换取成功。同期完成 V0–V3 目标达成回顾，确认四个版本退出条件达成并登记对话能力缺口（AR16–AR18）作为 V4/V5 输入。

**关键结果**：

- 完成 AR3-1–AR3-8 共 8 项任务；AR15 拆分为 AR3 系列后关闭
- 系列首轮复评 6.3/10，闭环复评 8.3/10 通过，V3 退出条件满足
- New-Pipeline Rate 保持 0：第二目标与主题发现均经统一 Capability Registry 接入，未新增顶层聊天 Pipeline
- 真实只读回归：跨期对比成功交付两期照片依据；主题发现在 Stage 3 精确报出 30 秒外部模型超时，可实时定位、无隐式重试
- V0–V3 目标回顾 8.0/10：四个版本退出条件均有证据链；无多轮连续性、无历史压缩、入口封闭分类三项缺口确认并登记

## 任务总览

- 目标契约：AR3-1，目标拥有完成要件、允许能力/观察与交付变体，Runtime 核心通用化；AR3-6 补齐跨期目标两期独立权威范围。
- 能力分层：AR3-2，Capability 注册表补全 Tool/Skill/Workflow 层级与完整契约，决策按目标筛选能力。
- 第二开放目标：AR3-3，只读照片跨期对比接入，复用范围解析、检索与详情能力。
- 主题发现 Workflow：AR3-4 能力化封装，AR3-7 补生产入口（`runtime_topics` 类别）。
- 评估与回归：AR3-5 组合轨迹基线，AR3-8 补完整多目标图级轨迹与物理隔离的真实回归入口。
- 已取代：AR15，Runtime 通用性问题拆分为 AR3-1–AR3-5 后不再以父任务保留。

## 主要变更

### 目标契约与通用 Runtime

- 任务状态拆分为通用核心（约束、已确认事实、产物引用、进度、错误）与目标领域状态；新增目标只需声明契约与能力组合，不改 Runtime 循环、全局归约或完成检查表。
- 删除从用户描述关键词推断交付模式的做法；目标与交付变体仅由入口识别结果或显式结构化参数确定。
- 跨期对比目标持有 `earlier`/`later` 两个独立的权威范围、候选与照片证据组，范围解析与检索声明期别且只归约至对应组，第二期检索不再覆盖第一期证据。

### Capability 分层

- 注册表为每项能力声明层级（Tool / Skill / Workflow）、适用与不适用条件、输入输出、错误语义和副作用。
- 决策上下文按当前目标只展示允许的能力；跨期目标确定性拒绝 `write_post` 等发帖专属观察。

### 新增能力与入口

- `compare_photo_periods` 只读 Skill：基于两组照片证据形成对比结论，交付可追溯的对比报告与引用照片，不选片、不生成文案、不写入草稿。
- `discover_topics` Workflow：显式范围下推至既有三阶段主题发现管线，输出单个主题候选 Observation；范围已建立后直接读取状态范围，避免重复定位。
- 入口分类显式区分发帖、跨期对比、范围化主题发现三个开放目标（`runtime_post` / `runtime_comparison` / `runtime_topics`）。

### 评估与回归资产

- 完整图级离线回归覆盖两个目标的入口选择、能力调用顺序、范围内证据和终态交付；V3 基线报告 Capability Selection Accuracy、Reuse Rate、New-Pipeline Rate、Contract Failure Rate、Task Success/Cost。
- 真实数据/真实 LLM 回归脚本落位 `agent/scripts/regression/live/`，与日常测试物理隔离，仅在当轮明确授权时执行；每步与每次 LLM 调用实时输出并可重定向落盘。

## 验证结果

- 离线全量回归通过（含本轮新增的 Runtime 图级轨迹、主题稀疏候选与 LLM 工厂重试回归）；定向 `test_llm_factory`、`test_runtime_v3_contracts`、`test_runtime_capabilities` 共 60 项通过。
- 首轮交付时离线全量 305/305 通过；复评轮补齐图级轨迹后全部通过。
- 授权真实回归：跨期对比成功交付（trace `f93416119896`）；主题发现在 Stage 3 报出 30 秒外部模型超时，日志与 trace 可定位，不计为主题逻辑失败。
- V0–V3 目标回顾为纯代码走查与文档对照，未调用服务、LLM 或真实数据。

## 已知边界与后续入口

- AR16 / AR17（待规划）：会话多轮连续性与历史选择压缩缺失，已确认为 V4 内容本体，随 V4 规划展开为 AR4-x 系列。
- AR18（待规划）：入口封闭分类与新开放目标静默降级，已决策延后至 V4/V5 完成后独立评估；V4 仅承担入口的最小跟进识别切片。
- 主题发现 Stage 3 的外部模型超时可在后续细分为 temporary error，以给出更精确的恢复提示。
- BQ3 暂缓：自由只读 SQL 仅限受信任本地开发环境；进入共享、多人或生产环境前，必须按 [FR-11](../design/2099-01-01-future-requirements.md#fr-11-开发阶段的鉴权与自由-sql-查询收敛) 恢复鉴权并收紧查询能力。
