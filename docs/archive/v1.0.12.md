> 归档日期：2026-08-26  
> 涵盖范围：v1.0.11（2026-08-25）之后完成的任务  
> 版本主题：**检索评估闭环与统一选图**

## 版本概述

本版本将连拍组检索、黄金用例管理与自动化回归收敛为可验证的检索质量闭环；同时统一应用内的选图与已选照片展示交互，补齐对话检索结果的缩略图反馈，并完成两个大型前端视图的职责拆分。

**关键结果**：

- 完成 W12、GR1、CH1、TF1-1 至 TF1-10、PS7 至 PS9、QA1、M1、D1，共 19 项任务
- 全量 Done 任务复评为 8.4/10，通过；Go 全量测试、Agent 相关单测、三层真实种子回归、前端构建与关键选图浏览器回归均通过
- 三 Collection 检索支持 photo/fine/coarse 组图粒度，并以真实图库种子用例持续验证
- 黄金用例从 JSON 维护升级为可在界面新建、编辑、单条评估和追加期望照片的闭环，底层评估统一按单张照片处理
- 确立选图覆盖层与已选照片列表两个标准控件，黄金用例与主题发现均接入，清理两套旧选图实现

## 主要变更

### 组图检索与质量评估闭环

- 新增精细组与模糊组两个向量集合，仅索引连拍组封面；全量照片集合保持原有行为。检索、清理和组重建均按粒度联动。
- 黄金用例曾支持粒度引用，并据此按集合评估；最终用户语义收敛为单张照片，保留连拍组的选图与展示便利，但保存、读取、追加和评估统一按单张照片处理。
- 建立 L0 数据态、L1 函数级、L2 HTTP 级三层 CLI 回归，沉淀检索和连拍组粒度两条真实种子用例；失败结果可定位至用例、断言和层级。
- 管理界面支持新建、编辑、单条运行、查看命中/未命中/多余命中，并由用户确认后将多余命中追加为期望照片。

### 统一照片选择与展示

- `PhotoPickOverlay` 复用图片管理的浏览、筛选、分段、全选和区间选择能力，通过会话协议回传结果并保持发起方草稿。
- `SelectedPhotoList` 提供通用的已选照片卡片网格、连拍组 ×N 展示、精选、移除和可选排序；黄金用例新建页率先接入。
- 主题发现的手动选题和步骤编辑器迁移到覆盖层；移除 `SuggestPhotoSelector.vue` 与无引用的 `GoldenPhotoPicker.vue`。
- 对话单张检索结果补齐缩略图、预览与下载路径，并按当前浏览器或 Wails 运行环境重建图片地址，修复远程访问历史消息图片的问题。

### 可维护性与回归保障

- 导入三步流程与黄金用例管理页拆分为职责明确的子组件，父视图分别由 1010 行降至 716 行、由 1408 行降至 916 行。
- 增加不写入业务数据的 Playwright 回归，覆盖打开选图覆盖层、取消选择及草稿恢复。
