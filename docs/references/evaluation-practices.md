# 评估实践参考

本文记录评估模式的外部依据与借鉴范围，供追溯来源或修订标准时查阅。具体分类、影响等级和通过条件是本地改编，不是官方统一量表。

- [评估模式](../harness/top/mode-evaluation.md)：本地改编后的操作规则。
- [社区 Harness 实践](https://martinfowler.com/articles/harness-engineering.html)，Birgitta Böckeler：区分功能行为、架构适配与可维护性，按成本安排确定性检查与语义评审。
- [OpenAI Harness 实践](https://openai.com/index/harness-engineering/)：通过架构约束、检查和独立评审提高产物可靠性。
- [Anthropic 代码评审](https://claude.com/resources/articles/code-review)：核实发现、过滤误报、按严重度排序。
- [Anthropic Agent 评测](https://www.anthropic.com/research/demystifying-evals-for-ai-agents)：按任务选择判据，用人工反馈校准。当前仅借鉴判据设计，不引入批量 Agent 评测体系。
