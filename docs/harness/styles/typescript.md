# TypeScript 与前端代码规范

修改 TypeScript 或 JavaScript 时，与[通用代码规范](code.md)一起读取；界面行为同时遵循[前端与交互原则](../FRONTEND.md)。

1. 沿用项目框架、包管理器、格式化及类型检查配置；未采用其他管理器的 Web 项目优先使用 `pnpm`。
2. 对服务端输入和外部数据先校验再使用；区分缺失、空值、空集合与零值。不要用类型断言掩盖尚未确认的数据结构。
3. 由明确的模块管理状态；组件之间通过清楚的输入与事件协作。派生数据尽量从现有状态计算，避免维护多份可独立变化的副本。
4. 为异步操作明确成功、失败、取消与过期结果的处理；按流程需要清理订阅、计时器及监听器。
5. 复用项目既有组件和测试工具，按行为编写断言；类型检查、构建与交互验证分别证明其能覆盖的部分。
