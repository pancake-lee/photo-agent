# 参考资料写法

`docs/references/` 保存外部资料、来源摘要与项目使用的约束事实，供追溯或指定任务按需读取。

1. 记录标题、作者或机构、链接、查阅日期；版本敏感的资料注明版本或适用日期。
2. 在本地概括与当前决策有关的结论、适用条件及限制；明确区分来源原意与本地推断、采用或舍弃的理由。
3. 外部产品文档或设计稿作为输入时保留入口和有效版本；本项目确认的行为与设计分别写入规格、设计文档。
4. 引用遵守合理篇幅，避免复制整篇文章；受众与加载条件按[审批规则](../top/RULES.md#文档与链接类型)标记。
5. 来源更新影响既有结论时，先核对差异，再提出规则或设计修订；引用更新本身不代表本地规则自动改变。
