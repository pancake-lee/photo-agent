# 记录性文档规范

记录讨论、调研、评估与复盘时读取本文。

1. 标明时间、目的与范围；先写当前结论，再给支持判断的事实。原话、观察、推断与建议分别表述，未知内容不补写成事实。
2. 保留足以复核的信息：来源或产物位置、必要原文、关键取舍及理由；运行记录注明环境、命令、结果和未验证项。
3. 用户反馈允许先保留较完整的上下文，注明当前理解、已确认结论与适用层次；提炼为 Harness 规则时另行审批。
4. 新反馈改变判断时，明确撤回或修正原结论，并记录原因；活动记录更新同一主题，避免相互矛盾的结论并存。
5. 总结围绕记录目的组织，不逐轮抄录操作过程；没有内容的章节省略。归档后冻结，后续纠正写在活动文档并引用历史。

个人学习、经验文章使用平和的个人叙述；规范与验收记录使用明确动作和可核对事实，分别采用适合用途的语气。
