# 文档治理规范

组织、拆分或维护各类文档及文档组时读取本文，适用于各工作模式。

## 信息分层与维护

- 根据文档用途和读者需要组织核心内容与支撑材料。核心内容呈现主要结论，以及影响理解、判断或行动的信息。
- 详细材料保存有追溯价值的背景、来源、推导、关键取舍与演变过程，供按需查阅。独立方案、清单和报告维护各自正文，核心入口保留摘要与必要链接。
- 由同类资料的主入口维护索引。专题正文和任务交接可直接链接需要查阅的规格、设计或证据。
- 按阅读和维护需要选择同一文档分层或拆分文档，复用已有载体。涉及任务进度及完成标准时，由选定的清单统一维护，其他位置按需引用。

## 阶段材料维护

- 阶段结束或工作重点切换时，检查材料的后续用途。仍需执行、决策或修订的材料继续留在活动区。
- 将已完成材料中仍生效的结论、约束、未决事项及下一步，提炼到现有核心入口或交接摘要，保留必要引用。
- 已完成且主要供回查的清单、比较和报告，移入就近的 `_archives/`。归档前核对承接信息与活动入口，归档后遵循冻结规则。

## 知识材料的聚焦与边界

- 知识说明遵循“局部准确、边界明确、不过度展开”：围绕当前知识点给出明确、可复述的结论，不为覆盖完整业务链路而罗列所有外围保障。
- 先说明当前机制直接解决的问题，例如原子命令消除哪一段并发窗口；不得把局部机制扩大成全链路正确性保证。
- 外围责任仅在缺少它会让当前结论失真时，用一句边界说明带过。除非当前问题要求完整方案，不追加数据库约束、状态机、结果重放等兜底清单，也不使用“等方案”收尾。
- 评估知识材料时，区分事实错误、必要的作用域收紧和合理的聚焦式省略。未展开外围机制不自动视为知识遗漏；只有它属于当前学习目标的重点时，才作为后续独立主题记录。
- 修正文案优先做最小改动，保留原问题的中心和面试复述价值。不得用面面俱到但失去重点的长答案替换原文。

## 评估学习笔记

- 以学习目标为尺度：先明确材料的用途、范围与抽象层次，在这些前提下评估，不套用更广场景或更高完整度的要求。
- 结合上下文理解原意：判断作者实际表达的结论，不将局部表述扩大为普遍承诺。术语或组织方式不同不自动构成错误，需判断是否造成实质误解。
- 以具体影响决定是否纠正：每项问题都须说明原文会导致什么错误理解或判断。仅增加形式严密性、例外覆盖或泛化提醒，而不改善当前知识点理解的建议，不输出。
- 区分错误、省略与未知：合理简化不作为缺陷，未核实不等于错误；问题严重程度取决于对核心理解的影响，并与用户要求的评估深度一致。允许得出“未发现符合条件的问题”。
- 修订保持最小必要：保留原文的中心、结构与复述价值，只修正造成误解的部分；不借评估扩展知识体系或补齐外围保障。
- 结论必须可核对、可执行：按“位置、原文引用、错误原因、可直接替换的修正版”输出问题，明确替换范围；同一根因统一说明，不重复夸大问题数量。
- 新信息改变前提时重审结论：用户澄清意图或范围后，重新判断问题是否成立，撤销失效建议，而非换一种说法继续保留。
