# 聚类结果审阅产品规格

- 状态 · 已确认

- 设计范围 · 聚类运行、结果浏览、主题生成与校验

## 需求结论

摄影者可从已有照片向量发现相似照片组，逐簇查看代表照片、生成主题说明并检查标题质量。

## 范围与行为

- 聚类页支持按参数启动分析、查看历史结果和删除结果。详情显示统计、每簇标题和描述及照片预览，支持展开成员。
- 单簇可生成主题或校验标题。批量操作确认后执行，校验结果可在详情查看。
- 缺少向量时提示先完成 Embedding。读取或操作失败时显示错误。
- 运行入口当前可能在服务端接受任务后提示失败。任务仍可在后台完成，重新进入聚类页可查看已保存结果。
- 批量界面提供「仅处理含错误的结果」。现有实现使用评估映射中的簇 ID，映射也可能含已通过的簇。

## 验收条件

- CLUSTER-A1 · 用含相似照片与离群照片的向量集合启动聚类，按任务 ID 查到完成后刷新结果列表，核对簇、噪声统计及成员预览。
- CLUSTER-A2 · 对一个簇生成主题并校验。检查报告在相应簇中显示。批量运行前核对实际目标簇，取消时保持当前结果。
- CLUSTER-A3 · 从空集合启动，核对引导与错误反馈。
