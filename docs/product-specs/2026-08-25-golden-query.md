## 需求结论

维护者可以为一条查询保存期望照片，比较检索的命中、漏检与额外命中。固定回归用例可定位数据、检索函数或 HTTP 契约的失败。

## 范围与行为

- 管理 · 支持新建、编辑、删除、导入及导出用例。用例保存问题、分类、备注和期望照片。
- 选图 · 新建时可按连拍组选取和精选。保存后的期望以单张为单位，详情编辑以更新后的照片集为准。
- 评估 · 支持单条或全量。查看命中、未命中和额外命中，经确认可将额外命中追加到用例。
- 回归 · 开发配置按用例标记所需检索粒度和断言。维护者可按用例与层级运行。

## 验收条件

- TF-A1 · 新建含连拍组的用例，保存后检查单张期望，编辑后核对照片集合与文本。
- TF-A2 · 对有命中、漏检和额外命中的用例执行单条评估，核对三类结果与资产状态，追加选定照片后复查。
- TF-A3 · 对标记用例核对三层断言。人为隔离目标照片、语义检索与 HTTP 契约的故障，核对报告能定位对应层级。
