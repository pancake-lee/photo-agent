# 图文工坊产品规格

- 设计范围 · 照片编排、文案生成与润色、草稿保存和导出

## 需求结论

摄影者可以带着自选照片、主题提案或已有初稿进入图文工坊，编排照片并形成可编辑、可续写、可导出的帖子。

## 范围与行为

- 入口 · 图片管理带入已选照片，主题发现带入提案标题、叙事内容和照片顺序，草稿管理恢复已保存的工作。也可直接打开工坊开始创作。
- 照片 · 支持搜索补图、拖拽排序、移除、查看大图和连拍精选。大图按当前照片序列切换，连拍可选出成员作为独立照片。
- 文案 · 提示词模式根据照片和可选要求生成标题、正文。润色模式以已有初稿为输入，可参考配图，保留原文结构与事实。风格可选文艺、纪实、轻松、攻略或自定义，结果可继续编辑。
- 草稿 · 切换模式时分别保留提示词和初稿输入。保存后可继续编辑，恢复照片顺序、标题、正文、风格、模式及两份输入。草稿管理支持删除和手动切换「草稿」「已发布」。
- 导出 · 复制 Markdown 或纯文本、下载 Markdown、下载单张原图。ZIP 从已保存草稿导出，包含 Markdown 和照片原图，未精选的连拍组取组封面。

## 边界与失败场景

- 生成需要至少一张有 AI 描述的照片。润色可只用非空初稿，选了照片且全部缺描述时提示先补描述。
- 部分照片缺描述时继续处理，并提示缺描述张数。取图或生成失败时显示错误，保留当前编辑内容。
- ZIP 使用最后保存的内容。更新草稿时，空标题或空正文会保留已有值。

## 验收条件

- PS-A1 · 从图片管理带入单张和连拍组，从主题发现采纳提案。核对照片顺序、提案标题和叙事内容，完成补图、拖拽、移除及连拍精选。
- PS-A2 · 用有描述的照片生成文案，核对具体画面、叙事顺序和风格差异。润色同一初稿，核对结构和事实。仅有初稿时也能润色。
- PS-A3 · 分别使用全部缺描述、部分缺描述和格式异常的输入，核对错误、警告及原编辑内容。
- PS-A4 · 两种模式各保存一次草稿并重开，核对当前模式、两份输入、照片顺序、风格及文案。切换发布状态并删除测试草稿。
- PS-A5 · 核对文本导出和单张原图。保存含单张与连拍组的草稿后导出 ZIP，核对 Markdown、单张原图与组封面。
