# 未来需求

本页保存暂未启动的需求。启动时在 [backlog](backlog.md) 记录任务、取舍与验收条件。来源为 2026-08-22 的需求审阅及后续补充。

## FR-1 评估体系扩展

检索黄金用例、聚类启发式规则和 Runtime 多轮评估已有各自基线。后续按路由或交付目标补充稳定用例、指标与验收口径。 [评估基线](eval/baseline.md)

## FR-2 多轮对话上下文感知

已由 V4 交付。 [多轮上下文记录](version/v1.0.19.md#有界会话上下文与跟进消解) · [对话多步任务规格](product-specs/2026-08-28-agent-tasks.md)

## FR-3 摄影报告生成

按年度或指定期间汇总器材、拍摄时间、主题与代表作品，形成可复盘的叙事报告。已有照片统计与跨期对比可提供输入。

## FR-4 发布历史分析

为已发布内容记录状态，按主题、频率和时间查看分布及缺口。启动时明确何种动作算发布。

## FR-5 系列感维护

在历史作品间发现可延续、对比或变奏的主题。发布历史或已有选题历史可作为输入。

## FR-6 时间线规律维度重新设计

从跨年拍摄记录找出重复出现的季节、题材或地点，提出可延续的选题。时间规律也可作为 FR-5 的输入。

## 图片管理的卡片大小

提供每行 1、2、3、5、8、12 张六档。按实际列表宽度限制可生效的档位。滑到超限档位时，维持当前卡片大小。

## FR-7 详情面板读写模式区分

按使用场景决定详情面板的元数据编辑权限。当前图文工坊隐藏 AI 处理入口，仍复用部分元数据编辑能力。启动时确认字段和保存责任。

## FR-8 草稿字段清空能力

空标题或正文沿用已保存值。用户有明确清空场景时，再定义相应的更新契约。提示词和初稿输入已可清空。 [草稿设计](design-docs/2026-08-23-post-studio-feature-design.md)

## FR-9 图文工坊提示词默认内容策略

当前提示词模式预填通用行程要求。根据使用反馈评估预填示例、占位文案或可选模板。

## FR-10 旅行第 N 天选片与社交文案查询

已由 Agent Runtime 承接。活动起始日和首个拍摄日推算结果不同时，请用户确认日期。 [对话多步任务规格](product-specs/2026-08-28-agent-tasks.md)

## FR-11 开发阶段的鉴权与自由 SQL 查询收敛

当前默认服务保留开发阶段的免鉴权与自由只读 SQL。进入非受信任网络、多人协作或真实用户环境前，恢复鉴权并收紧查询能力，验证未授权调用无法读取数据库。 [BQ3 任务](backlog.md#bq3-未鉴权服务暴露任意-sql-查询)
