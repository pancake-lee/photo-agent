# AR3 Capability System 复评

> 评估对象：AR3-1 至 AR3-5（目标契约、Capability 分层、跨期对比、主题发现 Workflow、组合基线）。
> 参照：[V3 Capability System](../../design/architecture/05-photo-agent-v3-capability-system.md)、[任务详情](../../backlog.md)、[V3 基线](../baseline.md)。
> 范围：代码与离线回归走查；未启动服务，未读取真实照片、未调用真实 LLM。

## 摘要

**6.3/10，通过但存在 3 项 P1 待规划问题。**

目标契约、能力层级和只读副作用边界已落到代码，既有发帖 Runtime 回归也保持通过。但跨期对比不能保存和物化两组独立范围，主题发现没有生产入口可选择其目标，V3 基线也没有穿过完整 Runtime 的两目标组合轨迹。因此，本次通过只表示现有离线单元级实现可运行，不表示 V3 退出条件已经被验收。

## 分维度评分

### 代码质量

- **正确性：5.8/10**
  - 得分点：`Goal` 显式声明允许能力与观察；`reduce_observation` 会拒绝目标不接受的观察。对比 Skill 输出包含两期 ID，且声明无副作用。
  - 失分点：跨期流程只有一份 `Scope` 和 `candidate_ids`；检索的 `period` 只在 Observation 中记账，不会形成对应期别的范围或过滤。两期事实不能被状态模型确定性表达。
- **健壮性：6.2/10**
  - 得分点：Capability 的参数类型、允许能力和错误状态仍经现有 Guardrail 校验；对比 Skill 对缺失证据与缺失详情分别返回结构化错误。
  - 失分点：`period` 是任意 `str`，除 `earlier`/`later` 外会静默不入组；而跨期正确性依赖该字段。主题发现目标无入口，运行时异常与空结果路径未经过生产 Router 验证。
- **可维护性：7.6/10**
  - 得分点：Tool/Skill/Workflow 的机器契约集中在 `Capability`；目标预设、归约和最终输出有清晰的显式分派。
  - 失分点：注册表列出三层能力，并不等价于每层都具有端到端可达性；主题发现目标定义、注册和入口分散后出现断链，当前测试未暴露。
- **简洁性：7.5/10**
  - 得分点：主题发现仅增加适配层，未重写既有三阶段管线；对比能力复用照片详情缓存与 Observation。
  - 失分点：为跨期收集引入 `period` 记账，却仍保留单一范围/候选语义，产生无法完成完整任务语义的半层抽象。

### 功能效果

- **准确性：5.0/10**
  - 得分点：替身测试证明已知两组 ID 可被对比 Skill写入报告并回显引用。
  - 失分点：该测试直接提供 `earlier_ids` 和 `later_ids`，跳过实际两期范围和检索；它没有证明判别用例会收集正确照片。
- **完整性：5.3/10**
  - 得分点：社交发帖、对比、主题发现均有目标类型和完成检查入口；注册能力覆盖 Tool、Skill、Workflow 三层。
  - 失分点：设计要求的跨期两组范围、主题发现开放目标入口、两个目标的完整轨迹均缺失或未验证。AR3-3 到 AR3-5 的关键验收未闭合。
- **一致性：7.0/10**
  - 得分点：三类能力复用统一 Registry、Observation、Guardrail 与最终输出形态；普通查询仍保留既有直达路由。
  - 失分点：入口对比目标的识别由 query_type 结果叠加关键词决定，主题发现没有同样的目标选择，开放目标间的路由语义不一致。

### 用户价值

- **惊喜度：6.0/10**
  - 得分点：跨期进步报告与范围化主题发现符合摄影库可提供的新洞察方向。
  - 失分点：当前未取得真实照片输出，无法确认结论是否真正建立了跨期关联。
- **可用性：5.2/10**
  - 得分点：完成后的对比报告会回显照片依据，主题候选有标题与理由。
  - 失分点：用户无法通过生产聊天入口请求 Runtime 主题发现；跨期请求的两期证据口径不能保证。
- **交互体验：5.0/10**
  - 得分点：Runtime 保留既有过程事件与终态输出机制。
  - 失分点：没有端到端的跨期或主题发现流程证据，无法验证入口命中、过程反馈和可理解的停止提示。
- **AI 增量：7.0/10**
  - 得分点：对比 Skill 以两组照片描述生成进步结论，主题发现复用稳定的 AI 选题管线。
  - 失分点：AI 的结论质量尚未在真实但只读的照片证据上回归，本次只验证替身返回的结构。

## 分任务评分

- **AR3-1：8.2/10** — 显式交付变体和目标观察边界可由单测证明，发帖兼容回归通过。
- **AR3-2：7.8/10** — 三层契约齐备并被 Registry 校验；端到端可达性未被契约测试覆盖。
- **AR3-3：4.8/10** — 对比 Skill 可处理预先给定的两组 ID，但 Runtime 无两期独立范围模型，未满足判别用例的证据收集要求。
- **AR3-4：5.5/10** — 范围下推和无历史写入的适配测试通过，但没有生产入口将请求送至 `GOAL_TOPIC_DISCOVERY`。
- **AR3-5：5.0/10** — 指标已记录且无真实 LLM 消耗；基线只验证直接函数调用，未覆盖设计承诺的完整组合轨迹。
